# Sonar Analysis Tool

## Purpose

Run SonarCloud static analysis on the **backbone-rest** project.

## Configuration

- **Organization**: `prx-open` (from `pom.xml` `sonar.organization`)
- **Project Key**: `backbone-rest` (artifact ID)
- **Host URL**: https://sonarcloud.io

## Commands

### Run Sonar Analysis

```bash
# Full build + Sonar analysis (requires SONAR_TOKEN)
mvn test org.sonarsource.scanner.maven:sonar-maven-plugin:sonar \
  -Dsonar.organization=prx-open \
  -Dsonar.projectKey=backbone-rest \
  -Dsonar.token=$SONAR_TOKEN
```

### Sonar Exclusions

Configured in `pom.xml` via `sonar.exclusions`:
```
**/*.xml, **/PrxBackofficeRestApplication.*,
**/config/*, **/config/jwt/*, **/config/security/*,
**/loggers/*, **/exceptions/*,
**/mapper/*, **/converter/*,
**/*Test*, **/session/*
```

### Coverage Source

JaCoCo XML report fed to Sonar:
- Path: `target/site/jacoco/jacoco.xml`
- Generated by: `mvn test`
