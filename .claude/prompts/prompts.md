## Variable Reference

Most prompts accept `${variable}` placeholders:
- `${domain}` — domain module name (`users`, `roles`, `contacts`, etc.)
- `${feature}` / `${title}` — feature name
- `${acceptanceCriteria}` — list of criteria or blank (auto-generated by product-owner)
- `${changedFiles}` — list of files for review
- `${scope}` — audit scope (blank = full codebase)
- `${version}` — release version tag
